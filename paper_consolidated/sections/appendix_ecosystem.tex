\section{Broader Small-Model Ecosystem Context}
\label{appendix:ecosystem}

The standalone inventory drafts in this project tracked the wider model ecosystem surrounding the evaluated \gls{slm} cohort. Their main function was to contextualize the paper within the rapidly changing 2025--2026 release cycle, where compact open models, open-weight reasoning models, and frontier API systems evolved in parallel. The distilled summary below preserves the most relevant ecosystem information inside the main paper.

\subsection{Landscape Snapshot}
\label{subsec:ecosystem_snapshot}
Three ecosystem trends are especially relevant to the present study:
\begin{description}
    \item[Capability compression] Reasoning, long-context handling, and multimodality have moved into the 1B--8B range, narrowing the gap between deployable \glspl{slm} and cloud-scale \glspl{llm}.
    \item[Open-weight acceleration] Families such as Qwen, Phi, Gemma, SmolLM, DeepSeek distills, Granite, and MiniCPM have expanded the design space for self-hosted deployment (Figure~\ref{fig:license_posture}).
    \item[Deployment diversification] Inference targets now span cloud GPUs, consumer GPUs, laptops, smartphones, browsers, and embedded edge boards, making model choice inseparable from hardware choice.
\end{description}

\subsection{Classification Conventions}
\label{subsec:ecosystem_classification}
The inventory drafts used the following practical conventions, which also informed the model-selection narrative in this paper:
\begin{itemize}
    \item Dense models at roughly 20B parameters or below were treated as \glspl{slm} when they remained plausibly deployable on modest hardware.
    \item Mixture-of-Experts models were interpreted using \emph{active} parameters for deployment reasoning, because active parameters better capture per-token compute and memory cost.
    \item Closed API models with undisclosed parameter counts were treated as frontier \gls{llm} baselines rather than direct members of the evaluated \gls{slm} cohort.
\end{itemize}
