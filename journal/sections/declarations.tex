\subsection*{Use of Generative AI}
A large language model assisted in compiling 205 of the candidate model records from public listings in March 2026 (Section~\ref{subsec:intro_method}). During revision, Anthropic's Claude was used to assist with editing the manuscript, checking bibliographic metadata against arXiv and Crossref records, writing the scripts that check each record's developer source and apply the inclusion rule, and transcribing the coverage ledger from the documents it cites. Figures~\ref{fig:hypothesis_conditions}, \ref{fig:taxonomy}, \ref{fig:breakeven}, \ref{fig:hetero_agent}, \ref{fig:falsification}, and~\ref{fig:inventory_pipeline} were rendered with an AI image-generation tool from figure specifications written by the authors; the authors checked every label, value, and connection against the text and corrected the rendered images where they differed. Every included record's developer source was checked through the Hugging Face Hub API or against the developer's own page, and the authors reviewed all generated output, verified factual claims and references against their sources, and take full responsibility for the content.

\subsection*{Data and Code Availability}
No benchmark was run for this review; all performance figures are reported values from public sources, whose provenance is given in \suppsec~\ref{app:provenance}. The following artifacts are provided as supplementary files with this submission and will be deposited in a versioned archival repository under a persistent identifier on publication: the variant inventory \file{merged\_llm\_database.json} (version~3.6), one record per variant with its parameter counts, C1/C2 status, inclusion decision and reason, developer source, the result and date of the source check, and a changelog naming every record added, moved, or removed between versions; the source-check log \file{source\_check\_log.csv}; the audit coverage ledger \file{audit\_coverage\_ledger.csv}; and the scripts that correct and verify the records, apply the inclusion rule, build the ledger, and generate every inventory table and figure (\file{fix\_records\_v3\_6.py}, \file{verify\_sources.py}, \file{apply\_inclusion\_rules.py}, \file{build\_audit\_ledger.py}, \file{generate\_model\_tables.py}, \file{generate\_figures\_v2.py}).
